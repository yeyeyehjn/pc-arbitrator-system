# 仲裁员PC端系统功能清单（重构版 v2）

> **更新说明**
> 本版基于原功能清单，结合重构需求对齐结果更新：
> 1. 重构目标：功能重组 + 体验升级
> 2. 核心模块（★）：首页功能区、我的案件、待办事项、案件详情页、个人中心
> 3. 次要模块：专家咨询、辅助功能
> 4. 新增方向：数据统计看板、移动端适配、智能化能力增强

> 6. 标注 **[新增]** 的为本次重构新增功能点；标注 **[建议]** 的为待确认的建议项，可增删

## 三、"我的案件"模块 ★核心

- 聚焦仲裁员个人承办案件的分类查询与进入详情办理。
- 进入“我的案件”页面，采用顶部为统计看板布局，展示在办案件、已结案件总数；下方为表格区域，点击统计数据显示对应状态的案件列表，点击案号进入案件详情页。
- 筛选项：案号、申请人、被申请人、案由、办案秘书、标的区间（万元）、开庭日期（日期选择器）、类型（全部、独任、首席、边裁）、结案类型（全部、裁决、调解、撤案）、快捷筛选（重大案件（标的超过1亿）、即将延期（审限即将到期，案号黄色高亮）、已延期（审限已到期，案号红色高亮））
- 列表字段：案件编号、申请人、被申请人、案由、标的（万元）、办案秘书、仲裁庭、组庭日期、开庭日期、案件审限（年/月/日（天数倒计时）（是否中止）（延期次数））、案件状态。

| 子模块 | 功能点 | 功能描述 |
| ---- | ---- | ---- |
| 在办案件 | - | 展示当前正在办理的仲裁案件列表，点击进入案件详情页 |
| 已结案件 | - | 归档已完成审理的仲裁案件，支持历史查询，点击进入案件详情页 |

## 六、"个人中心"模块 ★核心

管理仲裁员个人信息、职业资料及财务相关信息。

| 子模块 | 功能点 | 功能描述 |
| ---- | ---- | ---- |
| 个人信息 | - | 修改基本信息（姓名、联系方式、资质等） |
| 工作单位 | - | 登记或更新仲裁员所属执业机构、单位信息 |
| 个人履历 | - | 记录仲裁员教育背景、执业经历、专业领域等履历信息 |
| 酬金单 | - | 展示仲裁员参与案件的酬金明细、发放状态等财务信息 |
| 银行账号信息 | - | 维护用于接收酬金的银行账户信息（开户行、账号等） |
| 仲裁员聘书 | - | 查看或下载仲裁员聘任证书电子版 |

- 个人信息：
 - 基本信息：
   - 展示：姓名、身份证号、其他证件（证件类型、证件号码、有效期）、手机号码、性别、电子邮箱、居住地址、单位地址、其他地址、国籍/地区
   - 修改：其他证件（证件类型、证件号码、有效期）、手机号码、性别、电子邮箱、居住地址、单位地址、其他地址（居住地址、单位地址、其他地址支持三选一设置为首选地址功能）
 - 修改密码：支持短信验证方式修改、旧密码方式修改
   - 短信验证方式：短信验证码、输入新密码、确认新密码
   - 旧密码方式：输入旧密码、输入新密码、确认新密码

- 工作单位：修改单位名称、工作部门、职务、单位电话、工作状态（在职、退休）、单位传真、单位地址、备注、附件
- 个人履历：支持添加、删除、修改教育背景（起始日期、结束日期、在读院校、专业、学历、学位、附件）、外语能力（语种、附件）、与仲裁相关的培训或工作经历（起始日期、结束日期、单位/机构名称、职务/结业情况、附件））、主要专业成果（获得时间、成果名称、描述、附件）、工作背景信息（起始日期、结束日期、名称、描述）。
 - 除外语能力是按照添加时间升序，其余模块按照起始日期升序

- 银行账号信息：修改是否为公务员或参照公务员法管理机关（单位）工作人员（是、否）、是否为其他依法不取酬人员（是、否）、开户银行（下拉选择）、账户名称（不可修改）、银行账号。

## 七、"专家咨询"模块（次要）

支撑仲裁员开展专业咨询业务的管理。本模块为次要模块，重构时优先级较低，可后续迭代。

| 子模块 | 功能点 | 功能描述 |
| ---- | ---- | ---- |
| 专家咨询案件 | - | 查看仲裁员作为专家处理的咨询案件 |
| 申请专家咨询案件 | - | 查询仲裁员在办案件中有进行过专家咨询的案件 |

- 申请专家咨询案件：
  - 概述：仲裁员查看自己在办的案件中已发起专家咨询的案件列表
  - 筛选项：咨询标题、咨询秘书、咨询专业（金融投资、线下会议、港澳法律、建设工程等）
  - 列表字段：序号、咨询标题、咨询秘书、咨询专业、操作（查看专家意见）
  - 查看专家意见：
    - 咨询信息：查看标题、关联案件、咨询专业、争议焦点、案件审理报告、附件
    - 专家意见：查看专家对案件的咨询意见、建议、附件等

- 专家咨询案件：
  - 概述：仲裁员查看自己作为专家处理的咨询案件
  - 筛选项：咨询标题、咨询秘书、咨询专业（金融投资、线下会议、港澳法律、建设工程等）、处理状态（全部、待处理、已处理）
  - 列表字段：序号、咨询标题、咨询秘书、咨询专业、操作（回避/接受咨询、回复意见）
  - 回避/接受咨询操作：
    - 触发条件：待处理状态时，显示"回避/接受咨询"按钮
    - 操作流程：点击按钮 → 进入咨询详情页 → 查看咨询信息 → 选择以下方式操作
    - 方式1（线上确认）：在线预览声明承诺书 → 调用gdca电子签名功能 → 页面直接签名，无需下载
    - 方式2（上传文件确认）：下载声明及承诺书模板 → 上传扫描件 → 选择"回避咨询"或"接受咨询"
    - 方式3（退出咨询）：点击"退出咨询" → 系统确认提示 → 确认后更新状态为"已处理"
  - 回复意见操作：
    - 操作入口：未回复意见状态时，显示"提交意见"、"退出咨询"两个操作按钮
    - 提交意见流程：点击"提交意见" → 进入咨询详情页 → 查看咨询信息（标题、关联案件、咨询专业、争议焦点、案件审理报告、附件）→ 发表回复意见
    - 意见编辑：输入回复内容 → 支持上传附件（法律文书、证据材料等）→ 系统自动保存至数据库
    - 退出咨询：点击"退出咨询" → 系统确认提示 → 确认后更新状态为"已处理"
  - 咨询详情页内容板块：咨询信息展示区、回复意见查看区、发表意见编辑区

- 声明承诺书模板见 docs/声明承诺书.docx

## 九、[新增] 数据统计看板

为仲裁员提供个人办案数据的多维度可视化分析。

### 9.1 页面结构

| 区块   | 规则                                                                                          |
| ------ | ------------------------------------------------------------------------------------------- |
| 筛选配置区 | 筛选标题 + `清除筛选` 按钮 + 快捷筛选按钮组（今年 / 近半年 / 近三个月）+ 自定义日期范围（起始日期、结束日期选择器）+ 范围摘要文案（`日期 ~ 日期 · 共 N 天`） |
| 新收案件情况 | 环形图（独任 / 首席 / 边裁三类案件数及占比），环心显示总案件数；下方三块图例可点击跳转案件列表；按组庭时间统计                                                  |
| 在办案件情况 | 双格统计：在办数（非已结案案件数）、已延期数（有待开庭且过期的案件数）；已延期 >0 时玫红高亮；点击跳转案件列表；按组庭时间统计                                    |
| 办结案件情况 | 办结数（总数，含同比）+ 分项构成三格：裁决率、调解率、撤案率（各含同比涨跌 ▲绿色 / ▼红色）；点击各项跳转案件列表；按结案时间统计                                   |
| 图表区   | Top5 案由进度条列表；按组庭时间统计                                                                       |

### 9.2 筛选规则

| 筛选方式     | 规则                                                                                       |
| -------- | ---------------------------------------------------------------------------------------- |
| 快捷筛选     | 三按钮：`今年`（当年 1/1 ~ 今日）、`近半年`（今日前推 6 个月）、`近三个月`（今日前推 3 个月）；选中态高亮蓝色，手动改日期时自动取消高亮           |
| 自定义日期范围  | 起始日期 + 结束日期两个日期选择器；若起 > 结，自动纠正互换；范围变更触发短暂加载态（半透明 + `统计中` 脉冲指示器）                          |
| 清除筛选     | 点击 `清除筛选 ↺` → 回到默认"今年"范围                                                                 |
| 数据聚合逻辑   | 按日期范围与各年度季度区间取交集，纳入匹配的季度数据；多季度/跨年时，案件数求和、比率取算数平均、涨跌及排名取区间最近一期口径                           |

### 9.3 图表展示规则

| 图板             | 类型   | 展示内容                                                                                                       |
| -------------- | ---- | ---------------------------------------------------------------------------------------------------------- |
| 新收案件情况           | 环形图  | 独任（蓝 `#1E62EC`）/ 首席（橙 `#F59E0B`）/ 边裁（绿 `#74C080`）三类案件数及占比，环心显示总案件数；下方三块图例可点击跳转案件列表                              |
| 在办案件情况           | 指标卡片 | 在办数（非已结案案件数）、已延期数（有待开庭且过期的案件数）；已延期 >0 时玫红高亮                                                                  |
| 办结案件情况         | 指标卡片 | 办结数（总数，含同比涨跌）+ 分项构成三格：裁决率、调解率、撤案率（各含同比涨跌 ▲绿色 / ▼红色）                                                            |
| 办理案件 Top5 案由  | 进度条  | 横向进度条列表（TOP5 案由），显示件数与占比；点击案由名跳转案件列表                                                                          |
| 裁调撤情况          | 柱状图  | 四季度 × 三类指标（裁决率-蓝、调解率-橙、撤案率-绿），悬浮/点击高亮显示 Tooltip；日期范围覆盖到的季度高亮，未覆盖季度置灰；点击柱体聚焦到该季度日期范围 |

| 智能约庭增强 | 自动匹配仲裁员排期、庭审场地空闲时段，避开冲突，一键生成排期表 | [建议] |
| AI问答助手 | 内置AI助手，支持自然语言问答、法律检索、流程咨询 | [建议] |

- 智能约庭增强：基于仲裁员个人排期、仲裁庭组成情况与偏好、庭审场地实时占用数据，智能推荐最优庭审时段；自动检测并规避时间冲突（如与其他案件开庭时间、仲裁员个人日程冲突）；一键生成排期表并同步至个人日历，支持批量预约与灵活调整；同时提供约庭数据统计分析，辅助仲裁委员会优化资源配置与排期效率
- AI问答助手：内置AI智能助理，支持自然语言问答、智能法律检索、全流程业务咨询、辅助文书草拟等核心功能
 - 自然语言问答：支持仲裁员以口语化提问（如"如何发起延期审批"、"裁决书核阅的操作步骤是什么"）快速获取系统操作指引与业务规则说明
 - 智能法律检索：关联北大法宝权威数据资源，支持以关键词、案由、法条编号、案件类型等多维度检索法律法规、司法案例，提供类案参考、法条释义及适用建议
 - 全流程业务咨询：覆盖仲裁全流程（立案、组庭、开庭审理、文书制作、结案归档等），针对各环节的常见疑问提供分步操作提示与注意事项
 - 辅助文书草拟：支持根据当前案件基本信息（案号、案由、当事人、请求事项、证据清单等），一键生成文书初稿（如裁决书、庭审笔录、延期申请书等），仲裁员可在此基础上修改完善，提升文书制作效率
 - 上下文记忆：支持多轮对话交互，AI可记忆当前咨询的上下文（如同一案件的相关问题），无需仲裁员重复输入背景信息，提升沟通效率
 - 知识同步更新：AI知识库实时同步仲裁委员会最新规则、案例库、操作手册及外部法律更新，确保咨询内容的准确性与时效性

## 十一、[新增] 案件讨论聊天室

每个案件均设有专属聊天室，提供多方协作沟通与证据交换能力。聊天室按参与角色与使用场景划分为以下三类：

| 聊天室类型 | 参与角色 | 功能描述 |
| ---- | ---- | ---- |
| 案件讨论 | 三方：秘书、仲裁员、当事人 | 作为案件核心沟通群，支持三方围绕案件进展、争议焦点等进行实时讨论与交流，保障信息同步与协作效率 |
| 在线示证 | 双方：秘书、仲裁员 | 专供秘书与仲裁员进行证据材料的在线展示与质证沟通，支持上传附件、标注重点等操作，不对外开放 |
| 私聊 | 群内成员互相发起 | 支持群内成员（秘书、仲裁员、当事人）两两之间发起私聊会话，用于不便在公开群内讨论的私下沟通 |
