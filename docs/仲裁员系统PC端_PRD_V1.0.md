## 二、角色权限与统一规则

### 2.1 角色权限

- **仲裁员（主角色，本系统登录用户）**：
  - 查看首页工作台（待办统计、开庭情况、消息通知、日历、法律检索）；
  - 查询与管理本人承办案件（在办/已结）、进入案件详情办理（材料查阅、文书上传/编辑/签名、裁决书核阅、电子送达查询、案件讨论）；
  - 处理待办（承诺书签署、笔录签名、文书签名、延期审批、选择首席仲裁员、草拟裁决书、裁决书核阅）；
  - 维护工作日历可用时段（智能约庭第一阶段）；
  - 以专家身份处理专家咨询（回避/接受、签署声明承诺书、提交意见、退出咨询）；以申请人身份查看本人发起的专家咨询意见；
  - 维护个人中心（基本信息、密码、工作单位、履历、酬金查询、银行账号、聘书查看）；
  - 使用 AI 问答助手、案件讨论聊天室、辅助功能（文书指引）。
- **办案秘书（协作角色，非本系统登录用户）**：推送待办/消息、提交裁决书核阅、参与案件讨论与在线示证、担任咨询秘书。
- **当事人（协作角色，非本系统登录用户）**：参与"案件讨论"会话与私聊；不可进入"在线示证"会话。
- **审批管理员（协作角色）**：处理延期申请并回传审批结果通知。
- **权限边界**：本系统所有页面均要求登录态；数据范围限定为"当前仲裁员本人"的案件、待办、咨询与个人资料。

### 2.2 统一规则

**签名规则：**

- 手写签名统一复用 `SignaturePad` 全屏签名组件，操作按钮为 `取消` / `清除` / `确认签名`；
- 签名成功：`ElMessage.success` 提示、待办行移除、对应侧栏徽标数量 `-1`；
- 已签名文书再次点击 `签名`：提示"该文书已签名"并禁用按钮，不可重复签署。

**列表页通用规则：**

- 分页组件统一 `el-pagination`（`background` + `small`）：业务列表每页 `5/10/20` 条可选，`layout="total, prev, pager, next, sizes"`；通知中心为 `10/20/50` 条且含 `jumper`；辅助功能默认 `10` 条/页；
- 查询、筛选、切换 Tab/状态时一律重置到第 `1` 页；当前页超出范围时自动回到最后一页；
- 空状态分两级：无数据时显示"暂无XX数据"图标+文字；有筛选条件但无结果时显示"暂无匹配数据"，并提供清除筛选入口；
- 表格加载中显示 `v-loading`（品牌色 spinner）。

**导航规则：**

- 顶部导航（60px 固定置顶）：左侧 Logo + 系统名；中部主菜单 `首页` / `我的案件` / `待办事项` / `文书指引` / `个人中心`，选中项显示 2px 主题色底条；右侧通知铃铛（未读徽标，上限 `99`）、AI 助手图标、用户姓名下拉（含 `退出登录`）；
- 主内容区最大宽度 `1440px` 居中；
- 左右双栏页面（待办事项、我的案件容器、个人中心）：移动端 ≤768px 隐藏左侧栏，改为顶部 `el-select` 下拉导航；
- 路由守卫：未登录访问任何业务路由重定向 `/login?redirect=原路径`；已登录访问 `/login` 重定向首页。

**数据展示规则：**

- 案件标的：单位**万元**，右对齐、千分位格式化；重大案件阈值 `amount ≥ 10000` 万元（即 1 亿元）；
- 酬金金额：单位**元**，千分位 + 2 位小数；
- 案件审限复合格式：`YYYY/MM/DD（剩余 N 天）（未中止/已中止）（延期 N 次）`；剩余天数 `≤15` 天显示黄色、`<0` 显示红色并文案"已延期"；中止案件显示灰色 `已中止` 标签且不计入"即将延期/已延期"判定；延期次数为 `0` 时不显示该括号；
- 统计看板范围摘要：`YYYY.MM.DD ~ YYYY.MM.DD · 共 N 天`（N 含首尾）；URL query 用 `YYYY-MM-DD`；
- 时间格式：通知/咨询提交时间 `YYYY-MM-DD HH:mm`；列表日期 `YYYY-MM-DD`；
- 状态色全站统一：即将到期/待处理-琥珀 `#E6A23C`、已过期/危险-红 `#F56C6C`、通过/成功-绿 `#67C23A`、重大案件星标 `#F7BA0A`、统计看板涨-绿 `#67C23A` / 跌-玫红 `#E04B6F`；
- 手机号/邮箱等敏感联系方式脱敏展示（如 `138****1234`）；
- 空值统一显示 `—`。

**移动端适配规则（≤768px）：**

- 弹窗非全屏时 `width: 92%`、`margin: 5vh auto`；抽屉宽度 `90%~100vw`；
- `el-descriptions` 折叠为 1 列；统计看板筛选折叠为"摘要条 + 展开按钮"（展开为底部滑出抽屉）；
- 触摸目标 ≥ `44×44px`；`prefers-reduced-motion` 时停止脉冲动画；
- 移动端聚焦轻量场景（通知、案件查看、签署、开庭安排、待办），复杂操作引导至 PC 端。

**本期暂不做：**

- 智能约庭增强（自动匹配排期/场地/避冲突/一键生成排期表）——待办页仅保留占位空态，首页日历先落地"工作日历维护"第一阶段；
- 聊天室实时通讯（WebSocket）、已读回执、@提及、消息撤回、会话搜索、示证专用界面；
- AI 助手真实大模型与北大法宝 API 对接（当前为 Mock 意图路由）；
- 文书签名列表（提示"该功能暂未开放——后续实现"）、文书模板真实文件下载、聘书 PDF 下载、酬金单明细。

**其他规则：**

- 登录态持久化：`localStorage` 键 `gzac_token`（token）、`gzac_user`（用户 JSON）；AI 会话持久化键 `ai_assistant_session`（保留最近 1 个会话）；
- 操作成功/失败反馈：成功 `ElMessage.success` 且列表与徽标同步；失败 `ElMessage.error` 且列表保持不变；
- 危险操作（删除履历、退出咨询、删除周期规则）均需二次确认。

## 三、登录与鉴权

> 源自 FSD（全局导航：用户信息、退出系统）+ 现有实现（`LoginView.vue`、`auth.js`）。

### 3.1 页面结构

| 区块 | 规则 |
| ---- | ---- |
| 左侧品牌区 | 展示广州仲裁委员会标识、标语"立信铸就广仲 创新赢得未来"、版权信息 |
| 右侧登录区 | 标题"案件管理系统"；`账号登录` / `手机登录` 两个 Tab；`忘记密码` 独立模式（三步） |
| 账号登录-步骤1 | 步骤条"账号验证 → 双因素校验"；账号密码表单 + `下次自动登录` + `忘记密码` + `下一步` |
| 账号登录-步骤2 | 双因素校验：`短信验证码` / `邮件验证码` 方式切换、绑定联系方式展示、验证码输入 + `登录` / `返回上一步` |
| 手机登录 | 手机号码 + 短信验证码直登 |
| 找回密码 | 步骤条"身份验证 → 重置密码 → 完成" |

### 3.2 字段规则

#### 3.2.1 账号登录

| 步骤 | 字段 | 组件 | 必填 | 规则 |
| ---- | ---- | ---- | :-: | ---- |
| 账号验证 | 登录账号 | 文本输入框 | 是 | 支持账号或邮箱登录，placeholder"请输入账号/邮箱" |
| 账号验证 | 登录密码 | 密码输入框（含明/暗文切换） | 是 | 开启 Caps Lock 时实时提示"大写锁定已开启" |
| 账号验证 | 下次自动登录 | 复选框 | 否 | 勾选后维持登录态持久化 |
| 双因素校验 | 校验方式 | 按钮组（短信/邮件） | 是 | 切换后展示对应绑定联系方式（脱敏） |
| 双因素校验 | 验证码 | 输入框 + 获取按钮 | 是 | 获取后按钮进入 `60s` 倒计时禁用，文案"`Xs` 后重新获取" |

#### 3.2.2 手机登录

| 步骤 | 字段 | 组件 | 必填 | 规则 |
| ---- | ---- | ---- | :-: | ---- |
| — | 手机号码 | 文本输入框 | 是 | 输入绑定的手机号 |
| — | 短信验证码 | 输入框 + 获取按钮 | 是 | `60s` 倒计时禁用 |

#### 3.2.3 找回密码

| 步骤 | 字段 | 组件 | 必填 | 规则 |
| ---- | ---- | ---- | :-: | ---- |
| 身份验证 | 登录账号 / 手机号码 / 短信验证码 | 输入框 ×3 | 是 | 手机号须为账号绑定号码；验证码同倒计时规则 |
| 重置密码 | 新密码 / 确认新密码 | 密码框 ×2 | 是 | 两次输入须一致（复杂度规则见 11.3） |
| 完成 | 结果页 | 静态 | — | 提示重置成功，引导返回登录 |

### 3.3 交互规则

**登录流程：** 账号登录为两步式（账号密码 → 双因素校验）；手机登录一步完成；登录成功写入 `token` 与 `user`（内存 + localStorage），跳转 `redirect` 参数指定页或首页。

**登出流程：** 顶栏/移动端抽屉点击 `退出登录` → 清空内存与 `localStorage` 登录键 → 返回登录页。

**守卫规则：** 未登录访问受保护路由重定向 `/login?redirect=…`；已登录访问 `/login` 直接回首页。

**边界：** `立即注册` 链接为占位【待确认：仲裁员账号是否开放自助注册，见 T-02】。

#### 5.2.2 智能约庭（工作日历）

| 数据 | 字段 | 规则 |
| ---- | ---- | ---- |
| 单日设置 | `date`（YYYY-MM-DD 主键）、`status`、`reason`（≤50 字选填）、`segments` | `partial` 时 segments 含 `AM`/`PM` 各自的可用状态与事由 |
| 周期规则 | `id`、`weekday`（0=周日…6=周六）、`period`（AM/PM/ALL）、`reason`、`createdAt` | 同星期同时段不可重复（去重校验） |

日历日期 4 态：`available` 可用（白底）、`unavailable` 全天不可用（浅红底 + "休"）、`partial` 部分不可用（上白下红 + "半"）、已约庭（浅蓝底 + "庭"，只读）。
优先级：已约庭 > 单日设置 > 周期规则 > 默认可用；单日设置可覆盖周期规则，仲裁员设置不覆盖已约庭。

### 5.3 交互规则

**待办统计跳转：** 总待办 → `/todos`（默认签名列表）；承诺书/笔录/文书三类签名 → `/todos/signature`；延期审批、草拟裁决书 → `/todos/center`。

**消息通知：** 点击 `全部已读` 清除全部红点并同步顶栏徽标；`清除缓存` 清理本地缓存数据；FSD 中"关闭所有（关闭当前打开的所有通知窗口）"暂未实现【待确认，见 T-11】。

**日历维护：** 点击日期格弹出单日设置弹窗（480px）：状态三选一 / AM、PM 时段设置 / 事由 / `清除单日设置`；点击 `周期规则` 打开管理弹窗（560px）支持增删改；删除规则与保存均有防误操作确认/成功提示；由 `partial` 切为 `unavailable` 时自动清空 `segments`；过去日期允许设置。

**上下文记忆：** 进入案件详情自动携带案件上下文（案号/案由/当事人/请求），离开清空；草拟/摘要类指令无上下文时引导先进入案件详情页。

**发送队列：** 请求串行调度（Promise 链），loading 期间可继续排队；单次延迟 `600~1000ms`；异常兜底提示"AI 助手暂时无法回复"且队列不阻塞。

| 当前状态 | 触发动作 | 下一状态 | 触发方 | 说明 |
| ---- | ---- | ---- | --- | ------- |
| 默认可用 | 设置单日 `unavailable`/`partial` | 对应状态 | 仲裁员 | 可覆盖周期规则 |

## 十六、异常与边界场景

| 场景 | 处理规则 |
| ------------- | ------------------------- |
| 未登录访问业务路由 | 重定向 `/login?redirect=原路径`，登录后回跳 |
| 案件 ID 无效/已归档 | 详情页显示"案件不存在或已归档" + `返回` 按钮 |
| 标的区间最小值 > 最大值 | warning 提示"标的区间最小值不能大于最大值"，不执行查询 |
| 统计日期起 > 结 | 自动纠正互换后查询 |
| 列表无数据 / 筛选无结果 | 分别显示"暂无XX数据" / "暂无匹配数据"（含清除筛选入口） |
| 分页页码超出范围 | 自动回到最后一页 |
| 已签名文书重复操作 | 提示"该文书已签名"并禁用按钮 |
| 裁决书编辑器内容为空保存 | warning 拦截，不保存 |
| 周期规则同星期同时段重复 | 去重校验拦截，提示已存在 |
| `partial` 切换为 `unavailable` | 自动清空 AM/PM segments |
| 日历事由超 50 字 | 输入限制截断 |
| AI 助手请求超时（8s）/异常 | 错误气泡 + 重试入口；队列不阻塞；兜底文案"AI 助手暂时无法回复" |
| AI 草拟/摘要无案件上下文 | 提示"请先进入一个案件详情页"引导 |
| `填入裁决书编辑器` 时不在案件页 | warning 引导跳转 |
| 聊天消息超 1000 字 | 截断 + warning 提示 |
| 聘书图片加载失败 | 缩略图位显示"图片加载失败" |
| AI 会话 localStorage 读取失败 | 静默降级为新会话 |
| 修改密码两次不一致/复杂度不足 | 即时校验提示，不提交 |
| 银行信息"是否取酬"改为"是" | 确认弹窗提示影响酬金发放，取消则回退原值 |
| 履历结束日期 < 起始日期 | 校验拦截 |
| 退出咨询/删除履历/删除周期规则 | 二次确认，取消不产生变更 |
| 操作失败（接口异常） | `ElMessage.error`，列表与徽标保持原状 |
| 移动端弹窗/抽屉 | 非全屏弹窗 `92%` 宽、抽屉 `90%~100vw`，避免溢出 |
| 减少动态效果偏好（`prefers-reduced-motion`） | 停止脉冲类动画 |
