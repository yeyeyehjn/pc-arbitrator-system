## Design Specificity Verdict

中等偏低（约 4/10）：内容定制、范式通用。业务字段真实（案号+延期次数、两级审批流、退回上一级），但展示范式是任何企业 OA 的即插即用模板。品牌蓝仅剩提交按钮，深蓝司法权威缺席。

确定性扫描：detect.mjs exit 0 零发现（对照文件验证检测器生效）。手动抽查确认四档字号、无 em dash、无全局类重定义、无表格竖边框、3px 竖条未误用。检测器未捕获的额外问题：间距 14px/6px 违反 4 倍数、首区块缺标题、状态机矛盾。

## Priority Issues

1. [P0] 高风险默认值 + 无二次确认：审批结果默认"同意"，提交无确认，无撤销路径。修复：result 初始置空、提交前 confirm 摘要。
2. [P1] OA 节点状态文本冗余 + 审批后节点自相矛盾：待审批节点"审批意见：待审批/审批备注：待当前仲裁员审批"两行近义；e2 审批后旧待审批节点与新已审批节点并列（markExtensionApproved 追加式）。修复：待审批节点隐藏意见/备注行、数据层原位更新。
3. [P1] 首区块缺 section-title，四区块节奏断裂：案号 16px/600 与区块标题同权。修复：补标题、section-title 用 text-primary #00296b。
4. [P2] 品牌蓝缺席 + 状态色误用 + 当前节点无强调："待审批"用警告黄、已审批满屏绿、当前待审批节点无品牌蓝表达。修复：当前节点用品牌蓝，tag 用 info。
5. [P2] 区块无视觉边界 + 间距违反 4 倍数：row-gap 14px、margin-top 6px。修复：1px hairline 分隔、16px/8px。
6. [P3] 状态机/文案一致性：退回后 status='已审批' 无法追踪；"李四 仲裁员"vs"李四（首席仲裁员）"；flow 空无空态。
